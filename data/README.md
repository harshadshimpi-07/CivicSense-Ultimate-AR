# CivicSense Synthetic Dataset

- 82,000 synthetic civic issue records
- 27 columns
- Generated by `tools/generate_dataset.py` with a fixed seed for reproducibility
- Intended for dashboards, EDA, ML classification demos, severity prediction experiments and resolution-time analysis
- No real citizen personal information

Useful target columns include `category`, `severity`, `status`, `model_label`, `resolution_hours` and `estimated_cost_inr`.
